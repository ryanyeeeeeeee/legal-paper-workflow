# 论证与句段修订

用于正文构思、章节安排、逐段修改，以及“平铺直叙、读不明白、前后生硬、防御性太强”等反馈。先诊断论证，再处理表达。

## 1. 结构先于措辞

全文审查时，用简短提纲记录“这一部分回答什么—凭什么回答—如何推进中心论点”。只检查某一节时，将这个尺度缩小到段落即可，不要求额外制作整篇报告。

精简以论证任务为单位：

- 两处都在重复同一背景或同一判断，可以合并或保留功能更强的一处。
- 同一案例分别承担事实说明、风险机制和法律回应时，保留各自的新分析，压缩反复介绍的事实。
- 因果链的中间环节、适用条件和必要反证不能因追求短句而删除。
- 标题、章首和段首反复预告相同内容时，优先把正文改为实际分析，而非继续增加导入。

每节写多少段由其任务决定。用户要求先整体生成再修改时，先给完整小节，整体检查分工后再细改；逐段协作时持续保存该节的整体方向。

## 2. 法律论证要抵达具体环节

根据论文类型，检查以下关系中真正需要说明的部分，而非把它们机械填成固定句式：

| 判断 | 需要明确的内容 |
| --- | --- |
| 谁能影响结果 | 国家机关、融资方、项目公司、股东或交易相对方各自的权限与地位 |
| 什么利益受到影响 | 既有权利、权利行使条件、经营收益、后续开发或未来进入机会 |
| 影响怎样发生 | 资格、批准、表决、融资、履行或利益分配中的具体节点 |
| 法律手段怎样回应 | 谁能够使用，针对谁，在何时产生何种作用 |
| 论断有何根据 | 现行规则、约定条款、案例事实、可说明的推论或规范建议 |

区分股东与公司、直接与间接持股、公司损失与股东损失、合同当事人与其他受影响主体。区分行政决定、合作方同意和交易履行，不把其中一种权利写成对所有结果的控制。

提出法律工具时，先说明风险发生在哪个环节，再说明工具如何改变该环节的权利、程序、条件或责任。避免“企业可以行使股东权利”“可以通过合同约定保护利益”等止于常识的表述。

正文解释规则的作用，注释交代具体条文和文献。实在法上的权利、拟议合同安排与软法参考分别表述；不能把一种可协商方案写成现成的法定义务。采用具体规则作依据时，核对法域、效力、适用主体与条件；材料不足就标出缺口，不虚构权利或引文。

文体依论文任务选择。机制分析或制度研究中，使用读者能理解的权利、责任和程序语言；教义学术语只有在承担必要分析工作时使用，不为增加专业感而堆砌。

## 3. 让材料服务于推论

案例段围绕一个明确命题组织事实。保留足以支撑该命题的关键阶段和因果环节，结尾说明案例对当前问题的解释价值。事件时间线与资料介绍本身不能替代论证。

特别检查：

- 谈判或签约与完成批准、交割之间，是否存在尚未解释的环节？
- 融资支持通过什么条件影响经营选择，是否被省略成“融资方直接决定结果”？
- 两个事件先后发生，是否被误写为已经证明的因果关系？
- 正文分析的是未来作用机制，是否把结果提前写成确定事实？

证据所能证明的范围应直接限定命题。与其先下过大的结论再反复补“尚需核实”，不如写出材料实际支持的机制。资料状态与核验任务放在修改说明中；真正改变结论的限制仍应进入正文。

## 4. 修复承接，不能只补连接词

按三个层次检查：

1. **段落之间**：上一段留下的结果、疑问或条件，是否构成本段展开的理由？
2. **句子之间**：后一项是原因、后果、解释、补充还是对比？若关系无法说清，先调整顺序或补充中间环节。
3. **词语指代**：“这一安排”“上述变化”“由此”能否直接定位？主体是否在句中无提示地切换？

优先用有内容的承接，例如接续上一段已经形成的资金压力，再解释它为何改变决策空间。不要把“前述”“与此同时”“进一步”反复加在独立句子前，冒充逻辑关系。没有真实因果时不用“因此”，没有实质对照时不用“然而”。

“段首不平铺直叙”意味着首句能够推进问题，不意味着必须含转折词、复杂长句或宏大判断。相邻段落的开头也不必追求每句形式不同。

### 一个示意：补出关系后再润色

假设材料已证明追加投资、借款限制与开发计划之间的关联：

> 零散表达：追加投资扩大资金需求。贷款合同设置了财务指标。企业可能调整开发计划。
>
> 形成论证：追加投资扩大资金需求，而贷款合同中的财务指标又约束了新增借款空间，开发计划因而可能转向分期实施。

关键变化是交代财务指标如何作用于融资及开发，不能在材料未支持时仅凭连接词制造这条因果链。

## 5. 直接、清楚而不过度断言

- 删除重复保护自己立场的句子，例如段段声明“不意味着必然”“尚需结合具体情况”。
- 保留承载事实阶段或适用边界的“可能”“在……条件下”等表达；一次清楚交代后，沿着机制继续分析。
- 将“机制的形成与安排的推进对能力的提升……”等名词堆叠，改成明确主体、行为和作用对象。
- 拆解读者必须回读才能理解的长句；同时保留原因与后果的连接，避免拆成互不关联的短句。
- 不用“既有研究都忽视”“显然”“必然”等词替代证据，也不通过贬低既有合作来解释新方案的进入。

修改后做一次读者检查：首读能否知道谁在什么条件下做什么，为什么会产生这一结果？若只剩“应当协调、完善、保障”，继续把作用机制说具体；若已经清楚，就结束本处修改。
