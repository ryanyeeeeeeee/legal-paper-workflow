# 问题发现与论证检验

用于把选题兴趣转化为可以研究的法律问题，也用于定位既有论证中的断点。先弄清材料支持什么，再形成研究问题、解释和规范主张。

## 1. 何时使用

- **探索新选题或主线不清时**，依次检查下列问题，识别值得继续研究的矛盾、已有解释及证据缺口。
- **修改既有论证时**，从具体断点进入。例如只有后果描述而缺少评价依据，就集中检查评价；不要重新展开整篇选题。
- **已有可靠分析时**，复用已经成立的判断。新材料改变对象、条件或关键推论时，再回到相应环节核查。

可以往返修正前面的判断。无需每轮制作完整问答表，也不因某个问题暂时没有答案就中断其他有依据的分析。

## 2. 依次检查问题之间的关系

| 分析环节 | 要回答的问题 | 判断时的重点 |
| --- | --- | --- |
| 对象界定 | **是什么？** 研究的现象、概念或制度究竟指什么？ | 界定主体、行为、权利义务和研究范围；分清现实现象、法律概念与拟议安排，避免用宽泛主题代替对象。 |
| 状态与类型 | **什么样？** 它在实践中如何运行，呈现哪些类型或差异？ | 依据规则、案例或其他材料梳理实际状态，区分法域、主体、阶段和条件；个案表现不能直接当作普遍特征。 |
| 原因与机制 | **为什么？** 这种状态或矛盾由什么条件和行为形成？ | 交代触发条件、参与主体、决策环节及作用过程；检查其他可能解释，不能把时间先后或相关性当作充分因果证明。 |
| 条件与后果 | **会怎样？** 在不同条件下，权利行使、行为选择或利益分配可能怎样变化？ | 沿已经说明的机制推导后果，区分已发生结果与未来风险；需要时比较安排不变、风险触发及保障措施发挥作用等情景。 |
| 评价与意义 | **又怎样？** 这些变化为何构成值得研究的法律问题，对既有理解提出什么挑战？ | 说明评价依据和适用范围，识别权利保护、程序正当性、责任分配等具体问题；事实上的不利后果不能直接证明违法、制度失灵或改革必要。 |
| 回应与路径 | **怎么办？** 哪个主体可以在什么环节，通过何种法律手段回应？ | 将措施与问题发生的机制对应，交代法律依据、适用条件、可行性、代价及效果边界；区分现有权利、法律解释和制度建议。 |

对象和状态为成因解释提供事实基础；成因解释支持对后果的推导；后果的法律评价为回应方案提供理由。某一联系缺少依据时，指出断点及所需材料，不用连接词把它补成已经成立的推论。

尤其分清“发生什么后果”与“这些后果在法律上意味着什么”。例如，材料证明某种程序变化可能延长项目周期，只能先支持关于时间成本的判断；进一步讨论权利受损或程序缺陷，还需要明确相关权利、程序要求及其适用条件。

解释性或教义学论文可以通过澄清概念、修正解释或提出判断标准完成贡献。回应的形式服从研究问题，不强行增加政策建议或对策章节。

## 3. 用证据限定分析深度

对正在使用的判断，简要记录“当前回答—支持依据—未解决之处”；已有材料记录能够承担这一功能时，直接沿用。规则依据应核对法域、效力和适用条件，事实依据应能回到原始材料。

缺少材料时，将解释保留为假说，将未来后果写成有条件的推断，并明确下一步查证什么。不能为了回答所有问题而编造类型、成因、趋势或文献分歧。

对多个候选选题，依据问题是否具体、文献是否已经回答、关键材料是否可得，以及能否形成连续论证进行比较。未经文献与材料核验，不把潜在贡献写成已确认的研究空白。

## 4. 转入论证卡与章节安排

完成必要分析后，回到 `SKILL.md` 的论证卡，将结果集中为：

- **研究问题**：从已经识别的事实矛盾、解释困难或规范争议中提出可回答的问题。
- **讨论对象、中心论点与依据**：明确要回应的既有观点，提出材料能够支撑的回答，并保留尚待验证的环节。
- **贡献与边界**：说明回答带来的新认识，以及它能够解释或适用的范围。

再依论证依赖决定章节：哪些前提必须先证明，哪些分析可以合并，哪些回应需要以上游判断为基础。这些分析问题不预设章节数量，也不要求每个问题各占一章。用户仍处于资料或选题阶段时，交付问题线索与验证任务即可，不提前写成正文或最终提纲。

全文复核时，用同一组分析关系查找具体断点，并将需要修复的内容交给[审稿与交付](review-and-delivery.md)。已经解决的意见，只有出现新证据或实质缺陷时才重新开启。
