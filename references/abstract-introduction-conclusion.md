# 摘要、引言与结语

用于正文稳定后的首尾统一，也可在起草阶段辅助确定问题。以当前稿件的实际论证为准，不将旧稿摘要当作不可变的中心论点。

## 1. 先核对共同内容

从正文中提取研究对象、具体问题、中心论点、主要依据、学术贡献及适用范围，再检查三个部分的对应关系。核心术语可以重复，背景、完整案例与建议清单不必重复展开。

“制度能力”等核心概念只有在正文已经定义并说明其实现机制时，才能承担摘要或结语中的总结任务。润色不能临时创造一个更宏大的概念替代原有论点。

## 2. 摘要：让论证连起来

用户或期刊没有另行要求时，采用 **200—400 字、第三人称、尽量不使用“本文”“作者”** 的默认方式。通常依次承担以下功能，但不把每个功能固定为一句，也不强制四句或固定比例：

| 功能 | 要交代什么 | 常见偏差 |
| --- | --- | --- |
| 背景 | 触发问题的具体变化，简短进入主题 | 过长时事介绍，或第一句就讨论保护方案 |
| 讨论对象（fight） | 有根据的既有观点或分析前提及其具体局限 | 虚构“传统观点”，泛称研究不足 |
| 研究问题 | 该局限留下的具体疑问 | 只说“具有何种影响”而无对象和环节 |
| 中心论点（thesis） | 对问题作出的明确回答 | 换一种说法重复问题，或直接罗列措施 |
| 论据或机制 | 这个判断依据什么、如何成立 | 列章节名称、只宣布“分析了案例” |
| 贡献与意义 | 对法律理解、分析范围或制度回应推进了什么 | 泛称有意义，或把建议清单当贡献 |

fight 的强度由文献支持程度决定。“既有研究认为……”需要真实依据；只有部分研究支持时，应准确限定对象。没有足够证据时，围绕可以证明的分析取向讨论，不制造统一的“传统理论”作为靶子。

研究问题可以嵌入陈述句。中心论点与机制可以合写，但读者必须辨认得出问题的答案及其理由。贡献应体现由分析所得的新认识，不是“因为研究不足，所以具有价值”的循环。

### 修改任何一句后，都重读全段

- 背景是否自然引出讨论对象，而非突然转入文献评价？
- fight 指出的局限是否恰好导出研究问题，而非换成另一个问题？
- 论点是否回答这个问题，依据是否支持这个论点？
- 贡献是否从已有论证推出，是否与上一句重复？
- “因而”“相应地”“由此”等词是否有明确的逻辑前项？
- 字数是否符合要求，长句是否集中堆在末句？

交付完整、可使用的摘要。用户要求分析时，在摘要外简要说明问题、fight、thesis 和贡献如何对应；不要把这些标签直接写进摘要。

## 3. 引言：七项功能，不是七个固定段落

默认按下列顺序检查，允许相关功能在同一段完成，并服从用户保留段落安排的要求：

1. 以读者能够理解的背景引出领域中的变化或矛盾。
2. 概括相关研究已经解释了什么，承认其贡献。
3. 指出仍未解释清楚的具体环节，即研究缺口。
4. 从缺口提出本文实际能够回答的问题。
5. 说明如何处理问题，包括材料、法律关系或分析路径；只写实际采用的方法。
6. 预告论证推进的理由与方向，使读者理解各部分为何必要。
7. 说明问题被回答后，在法律理解或制度实践上增加了什么。

研究现状围绕共同问题和真实分歧组织，避免“第一类研究……第二类研究……”的机械清单，也避免逐个排列“某某学者认为”。作者与文献出处进入注释，需要对话的实质观点进入正文。

论证预告不必写“第一章……第二章……”。解释为什么从某个基础问题推进到机制与后果，再进入法律回应。也不以“核心主张”“论证从”一类提示标签代替清楚的表达。

## 4. 结语：从研究发现走向有边界的展望

开头接续正文最后解决的问题，提炼全文的发现及其法律含义。后一段应由这个发现进一步说明更广泛的启示，段落之间存在可辨认的推进关系。

保留以下内容中对该文必要的部分：问题的答案、机制的综合判断、法律分析带来的认识、适当范围内的未来展望。删去逐章回顾、重复背景、重新介绍案例、常识性宣言和具体工具清单。

宏观展望必须从已经论证的微观发现生长出来。研究某一地区、产业或法律环节时，可以说明它对同类问题的启示，不把它写成整个领域的完整法律基础。保留已经论证的中心概念，同时用其实际内容避免空泛收束。

## 5. 标题与期刊写法

章节标题体现研究对象和本章的分析任务，相邻标题要能辨认各自分工。调整过宽、重复或不能覆盖正文的标题，不为制造“学术新意”而增加生造概念。用户保留总标题决定权时，遵守这一边界。

用户要求学习国内外高水平期刊时，实际阅读与本论文体裁接近的代表性摘要、引言或结语，优先使用期刊、出版社或作者提供的原文。总结其问题提出、论证衔接和贡献表述方式，应用到本稿；不逐句仿写，不把少量样本称为所有期刊的硬性标准。说明实际读过的材料，已经获得足够依据后不在每次局部润色时重复检索。
